# 🚰 Fernando Plomería — Landing Page de Alta Conversión (Astro)

[![Astro](https://img.shields.io/badge/Astro-FF5D01?style=for-the-badge&logo=astro&logoColor=white)](https://astro.build/)
[![Vercel](https://img.shields.io/badge/Vercel-000000?style=for-the-badge&logo=vercel&logoColor=white)](https://vercel.com/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=for-the-badge&logo=tailwind-css&logoColor=white)](https://tailwindcss.com/)

Una landing page ultra-rápida, profesional y optimizada para dispositivos móviles, diseñada específicamente para campañas de **Google Ads** de servicios de urgencia (plomería, hogar y piscinas). 

Desarrollada en **Astro** para garantizar una carga instantánea (lo que reduce drásticamente el costo por clic y el porcentaje de rebote en campañas pagas) y un flujo enfocado 100% en la conversión a WhatsApp.

---

## 🚀 Características Clave

* ⚡ **Performance Extrema:** Construcción estática con Astro. Carga instantánea en móviles, crucial para clientes que entran con una urgencia de plomería a cualquier hora.
* 📈 **Optimización para Google Ads:** Estructura pensada para mejorar el *Quality Score* de los anuncios, reduciendo el costo por clic (CPC).
* 📱 **Mobile First & Accesible:** Diseño totalmente responsivo y adaptado al uso con una sola mano. Incluye respeto a `prefers-reduced-motion`.
* 🗺️ **SEO Local Integrado:** Incluye datos estructurados nativos de Schema.org (`schema.org/Plumber`) en el `<head>` para posicionar el negocio en CABA y GBA.
* 🔋 **Cero Dependencias Pesadas:** Iconos en SVG inline, sin librerías externas de fuentes o iconos que ralenticen la carga.
